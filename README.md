# Politico
Politician & Voter Registration Platform

A web application that allows politicians to register under a political party and users (voters) to register, browse, and cast votes for politicians.

🚀 Features

Politician Registration

Politicians can sign up and create profiles.

Each politician must select a party affiliation.

Party information is displayed on their profile.

User (Voter) Registration

Users can register securely with basic details.

Once registered, users can browse politicians and vote.

Voting System

Registered users can vote for their preferred politician.

Each user can cast only one vote per election cycle.

Votes are stored securely and counted in real time.

Dashboard

Politicians: view votes they have received.

Admin: manage parties, politicians, and oversee voting results.

Users: view the list of politicians and their vote counts.
